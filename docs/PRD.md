# 아로마티카 기업 분석과 성장 전략 대시보드

제품 요구사항 문서 v0.1 · 2026-11-26 · 캡스톤디자인(통계컨설팅)

## 1. 배경과 목표

발표 청중은 짧은 시간에 기업의 성과, 실적 변화의 근거, 제안한 성장 전략 사이의 관계를 파악해야 한다. 발표자가 같은 화면에서 요약과 원자료를 오갈 수 있도록 공시 수치, 계산 과정, 해석을 연결한다.

**핵심 질문** — 2023~2025년 아로마티카의 매출과 수익성은 어떻게 변했으며, 확인된 사업·재무 근거가 뒷받침하는 성장 기회는 무엇인가?

| 사용자 결정 | 설계 반영 |
|---|---|
| 캡스톤 발표용 | 교수·학생을 주 독자로 두고 발표 화면에서도 기간·단위·핵심 문장이 읽히게 구성한다. |
| 요약 후 상세 탐색 | 첫 화면에 결론과 지표를 배치한다. 발표자가 해당 차트, 전략, 출처로 바로 이동할 수 있게 한다. |
| 자료 검토 후 전략 선정 | 조사 단계에서 후보를 비교해 근거가 충분한 전략 1~2개를 선정한다. |

## 2. 화면과 발표 흐름

| 구역 | 화면에 담을 내용 | 사용자 행동 |
|---|---|---|
| 요약 | 기업을 소개하는 한 문장, 분석 기간, 검증된 핵심 결론, 매출액·영업이익·영업이익률·부채비율 카드 | 연도를 선택하고 카드의 산출 근거를 연다. |
| 기업과 사업 | 주력 제품군과 판매 경로, 공시상 확인되는 사업 특징 | 관심 있는 사업 항목에서 관련 자료를 확인한다. |
| 재무 분석 | 3개년 매출액·영업이익, 영업이익률 추이, 재무 비교표와 변동 사유 | 선택 연도를 전후 연도와 비교하고 원자료를 확인한다. |
| 성장 전략 | 전략별 관찰 사실, 제안 이유, 실행 방안, 성과지표, 위험 요인 | 요약 제안을 펼쳐 근거와 평가 방법을 확인한다. |
| 출처 | 자료명, 발행 기관, 보고 기간, 재무제표 기준, 원문 링크 및 위치 | 지표·전략에서 인용한 원문으로 이동한다. |

## 3. 데이터와 검증 규칙

- DART 연간 사업보고서와 감사보고서를 우선 확인한다. 정정 공시가 있으면 사용한 공시 버전과 정정 사항을 기록한다. 회사 공식 자료는 사업 현황과 전략 근거를 보완하는 데 사용한다.
- 2023~2025년 연간 연결재무제표를 우선 사용한다. 연결 자료가 없는 연도는 별도로 표시한다. 기준이 달라진 구간은 표와 차트에 표시하고 해당 구간의 전년 대비 증감 계산을 생략한다.
- 매출액·영업이익은 연간 실적, 부채총계·자본총계는 해당 연도 말 잔액을 기록한다. 각 값에 연도, 계정명, 원문 값·통화·단위, 연결 여부, 출처 식별자를 보관한다.
- 표시는 억 원과 %로 통일한다. 원문에서 단위를 맞춘 뒤 반올림 전 금액으로 계산한다. 영업이익률 = 영업이익 ÷ 매출액 × 100. 부채비율 = 부채총계 ÷ 자본총계 × 100. 영업이익률의 전년 차이는 %p로 표시한다.
- 결측은 데이터에서 null로 저장하고 표의 값은 비워 두며 옆에 사유를 표시한다. 차트는 결측 구간을 끊는다. 분모가 0이면 비율을 계산하지 않는다. 실제 0은 숫자 0으로 표시한다.
- 원문 URL과 페이지·표 번호를 보관한다. 페이지나 표 번호가 없으면 공시의 절·표 제목을 적는다. 수치와 변동 원인의 출처가 다르면 각각 기록한다.
- 분석 담당자가 원문 수치·단위를 대조하고 두 비율을 재계산한 뒤 화면 값과 비교한다. 자료만으로 설명하기 어려운 원인은 ‘확인 필요’로 표시한다.

## 4. 성장 전략 선정 방식

제품, 판매 채널, 해외 시장 등에서 후보를 찾는다. 각 후보에 대해 ① 근거가 되는 수치와 사업 사실 ② 회사가 실행할 수 있는 조치 ③ 성과를 측정할 지표와 필요한 데이터 ④ 예상 위험을 한 표에서 비교한다. 이 검토를 통과한 후보를 최대 두 개 채택하고 선정 이유를 제시한다. 근거가 부족한 후보는 조사 과제로 남긴다.

카드에는 ‘회사 공시’와 ‘분석팀 제안’의 작성 주체를 표시한다. 목표치·예상 매출은 산출 근거가 확보된 경우에만 제시한다. 효과를 사후 검증할 지표에는 산식과 측정 기간을 기재한다.

## 5. 기능과 인수 기준

| 기능 | 완료 판정 |
|---|---|
| 연도 선택 | 기본 연도는 2025년이다. 2024년 선택 시 네 지표와 각 출처가 함께 바뀌고, 3개년 차트에는 2024년이 강조된다. |
| 산식·출처 열기 | 비율 카드를 열면 분자·분모의 계정명, 원문 금액과 단위, 계산 결과, 공시 위치가 보인다. |
| 차트와 표 | 금액과 비율은 별도 차트에 표시한다. 연도·단위·재무제표 기준을 확인할 수 있고 같은 수치가 비교표에도 표시된다. |
| 전략 상세 | 키보드와 마우스로 전략 카드를 열고 닫을 수 있다. 제안에서 해당 근거 자료까지 이동할 수 있다. |
| 반응형 화면 | 발표용 데스크톱 화면에서 요약을 먼저 읽을 수 있다. 모바일에서는 카드가 한 열로 배치되고 넓은 표만 가로 스크롤된다. |
| 데이터 오류 처리 | 파일 로딩 실패는 오류 안내로 표시한다. 결측·실제 0·로딩 실패를 각각 구분할 수 있다. |

CSV 다운로드는 후순위다. 첫 배포는 검증된 데이터 조회와 발표 흐름을 우선한다.

## 6. 기술 구성과 진행 순서

GitHub 저장소에서 한국어 단일 페이지를 관리한다. `index.html`은 문서 구조와 탐색, `css/style.css`는 발표·모바일 레이아웃, `js/app.js`는 데이터 로딩·지표 계산·화면 갱신을 담당한다. 검증된 원자료와 전략을 `data/financials.json`, `data/strategies.json`에 분리하고 공통 출처 식별자로 원문과 연결한다. GitHub Pages 배포 시 저장소 하위 경로에서도 열리도록 상대 경로를 사용한다.

| 순서 | 산출물 | 종료 조건 |
|---|---|---|
| 1. 요구사항 정의 | 이 문서 | 사용 목적, 화면 구성, 전략 선정 방식 기록 |
| 2. 원자료 확보 | 3개년 원자료표와 출처 목록 | 기준·단위·원문 위치와 결측 사유 확인 |
| 3. 화면 스케치 | 요약·재무·전략 화면 시안 | 실제 사용 가능한 지표를 기준으로 발표 흐름 점검 |
| 4. 구현 | HTML·CSS·JavaScript 및 데이터 파일 | 필수 기능을 브라우저에서 실행 |
| 5. 대조 검증 | 원문 대조 및 기능 점검 결과 | 연도별 값·산식·출처와 모바일 동작 확인 |
| 6. 배포 | GitHub Pages 사이트 | 배포 주소에서 첫 화면·차트·원문 링크 동작 확인 |

## 7. 조사 후 보완 사항

2026-11-26 문서 대조 결과 필수 기능과 검수표 01~10의 범위가 일치한다. 사이트 기능 검수는 구현 후 수행한다.

- 자본총계가 음수인 연도는 부채비율의 산식 계산값을 상세 근거에 보관하고 카드에는 ‘자본잠식’으로 표시한다. 일반적인 양수 부채비율과의 비교는 생략한다.
- 자료의 감사 여부와 검증 상태를 데이터와 화면에 기록한다. 사업보고서 전재본에서 확인한 2023년 재무정보는 미감사 표시를 유지한다. DART 최종 원문과 정정 여부 대조를 완료한 자료를 발표용 확정 데이터로 사용한다.

## 8. 발표 전 확인할 질문

1. 매출과 영업이익률이 서로 다른 방향으로 움직인 구간이 있다면 그 이유를 원문으로 설명할 수 있는가?
2. 선택한 성장 전략이 다른 후보보다 우선인 이유를 어떤 수치와 사업 사실로 설명하는가?
3. 경쟁사 비교나 고객 데이터가 추가되면 현재 결론 중 무엇을 다시 검증해야 하는가?
