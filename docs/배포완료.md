# 배포 완료 기록

작성일 2026-11-28

## 주소와 운영 계정

- 공개 사이트 https://jdh204011-gif.github.io/aromatica-dashboard/
- GitHub 저장소 https://github.com/jdh204011-gif/aromatica-dashboard
- GitHub 계정 `jdh204011-gif`
- GitHub Pages 설정 https://github.com/jdh204011-gif/aromatica-dashboard/settings/pages
- 배포 방식은 `main` 브랜치의 `/(root)`다. 저장소와 사이트는 공개되어 있다.

## 확인한 항목

- 사용자가 공개 주소에서 사이트가 열림을 확인했다.
- 2024년 선택 시 매출액 525.96억 원이 보이는지 확인했다.
- 기업 개요와 제품 이미지, 창을 좁혔을 때 메뉴와 세로 배치를 확인했다.
- 자료 출처 메뉴의 링크가 표시됨을 확인했다. 링크의 실제 이동과 휴대전화 실기기 검수는 확인 필요다.
- 현재 로그인·팀원 편집·데이터베이스 연동은 구현하지 않았다. 팀원은 사이트를 읽고, 소유자가 GitHub에서 수정하기로 했다.
- 2023년 미감사 수치와 최종 DART 원문 대조 대기 표시를 유지한다.

## 내용 반영

GitHub 저장소의 `index.html`을 수정해 `main`에 반영하면 GitHub Pages 배포가 실행된다. 현재 재무 수치는 HTML에 직접 작성되어 있으며 `data/financials.json`을 수정하는 것만으로 화면이 바뀌지는 않는다. 수치 변경 시 지표, 차트, 표와 설명을 함께 대조한다. 반영 후 Pages 설정과 공개 화면을 새로고침해 확인한다.

## 비용과 자원

GitHub Pages 무료 사용을 전제로 한다. 별도 유료 API와 분석 작업은 현재 확인되지 않았다. 분석 1회 자원·비용은 실행 가능한 분석 경로가 없어 미측정이다. 관리형 무료 사용량 제한과 GitHub 계정의 과금 여부는 계정에서 확인 필요다. 별도 CPU·GPU 작업자는 없다.

Supabase 무료 프로젝트는 생성됐으나 이 사이트에 연결하지 않았다. 무료 프로젝트가 활동 부족으로 일시 중지될 수 있으며 현재 사이트 동작에는 영향이 없다. 프로젝트를 유지하거나 삭제할지는 소유자가 결정한다.

## 서비스 중단

사이트를 내리려면 GitHub 저장소의 Settings → Pages에서 배포를 해제한다. 저장소를 삭제하면 코드와 이력에도 영향을 줄 수 있으므로 중단과 삭제를 구분해 확인한다.

## 미완료

DART 최종 공시 대조, 링크 이동 및 휴대전화 실기기 검수는 남아 있다. 데이터 저장과 권한 검사는 현재 편집 기능이 없으므로 해당 기능을 추가할 때 수행한다.
