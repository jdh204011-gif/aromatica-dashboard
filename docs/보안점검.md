# 배포 전 보안 점검

점검일 2026-11-27

## 먼저 처리할 3가지

1. **로그인과 관리자 권한을 추가할 때 접근을 시험한다.** 비로그인 사용자와 일반 사용자의 관리자 기능 접근이 거부되는지 확인한다.
2. **데이터베이스를 연결할 때 접근 규칙을 확인한다.** 서로 다른 두 계정으로 읽기와 수정 권한을 시험한다.
3. **기밀 설정 파일의 이력을 계속 확인한다.** 기본 브랜치의 확인한 8개 커밋에 환경 설정 파일은 없었다. 다른 브랜치는 확인 필요다.

위 순서는 앞으로 배포와 기능 추가를 진행한다는 계획에 따른 우선순위다. 현재 비밀키 유출이나 권한 침해가 발생했다는 뜻은 아니다.

## 점검 범위

현재 작업 폴더의 `docs/PRD.md`, `docs/ACCEPTANCE.md`, `docs/FINANCIAL_RESEARCH.md`, GitHub `index.html`, `data/financials.json`을 확인했다. HTML 시안의 최신 저장본과 프로젝트 폴더의 파일을 대상으로 흔한 비밀값 형태 및 로그인·데이터 연결 코드를 확인했다. 자동 검색은 모든 형태의 비밀값을 찾아내지는 못한다. GitHub 기본 브랜치의 현재 파일과 8개 커밋의 변경 파일명을 추가 확인했다. 다른 브랜치, 데이터베이스 관리자 화면과 배포 설정은 확인하지 못했다.

|---|---|---|---|
| 코드에 API 키·비밀번호 직접 기재 | 양호 | 점검 범위 전체 | 흔한 키·비밀번호 형태는 발견되지 않았다. 새 서비스를 연결할 때 키를 코드에 직접 입력하지 않도록 확인한다. |

| 사용자 입력 검증과 안전한 출력 | 양호 | GitHub `index.html` | 자유롭게 글을 입력하는 양식은 발견되지 않았다. 연도는 선택 상자에서 고르고, 고정된 화면을 전환한다. 추후 검색·댓글·편집 기능을 넣으면 입력값을 확인하고 글을 HTML 코드로 실행하지 않게 처리한다. |

## 용어 설명

- **API 키**는 외부 서비스 사용자를 구별하는 값이다. 비밀 키는 다른 사람이 사용하지 못하도록 보호해야 한다.
- **.env**는 서비스 접속 정보 등을 보관하는 설정 파일이다.
- **.gitignore**는 Git이 새로 추적하지 않을 파일을 정하는 목록이다. 이미 올라간 파일의 과거 기록은 별도로 확인해야 한다.
- **Git 이력**은 코드가 이전에 어떻게 바뀌었는지 기록한 내역이다.
- **service_role 키**는 Supabase에서 높은 권한을 가진 비밀 키다. 브라우저에 넣으면 방문자가 확인할 수 있다.
- **RLS**는 데이터베이스의 행 단위 접근 규칙으로, 사용자마다 읽거나 수정할 수 있는 자료를 제한한다.
- **입력 검증**은 사용자가 보낸 값이 허용된 형태인지 확인하는 과정이다.

## 남은 확인

이 보고서는 발견된 파일과 제공된 정보에 한정된다. GitHub의 다른 브랜치 이력, 실제 로그인·데이터베이스 설정, 외부 서비스의 과금 한도는 확인 필요다. 코드와 설정은 이번 점검에서 변경하지 않았다.
